💡 Como Usar Parcelamentos

  1. Adicione um gasto parcelado: Na aba "Meus Gastos", defina quantas parcelas você quer (ex: 3 para compra de 3x)
  2. O sistema cria automaticamente: As parcelas aparecerão nos próximos meses com a descrição atualizada (Produto 1/3, 2/3, 3/3)
  3. Cada parcela é independente: Você pode marcar como pago individualmente conforme o cartão cobra
  4. Visualize futuro: Mude entre meses no selector para ver suas obrigações futuras
  5. Acompanhe parcelas: Na aba "Parcelamentos" você vê um resumo de tudo que está parcelado
  6. Organize financeiro: Veja com antecedência quanto você terá comprometido em cada mês
  7. Planeje melhor: Use os dados para entender seus gastos e não fazer compras que não caibam no orçamento
